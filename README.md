# Eksperimen_SML_Rizky
Proyek end-to-end Machine Learning Operations (MLOps) untuk sistem Credit Scoring. Repositori ini mencakup seluruh siklus ML: mulai dari pra-pemrosesan data, pelacakan model dengan MLflow, pipeline CI/CD via GitHub Actions, hingga serving API dan sistem pemantauan terintegrasi menggunakan Prometheus dan Grafana.
